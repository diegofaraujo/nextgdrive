Next GDrive

An open-source Google Drive client for Linux

Install Privacy Terms Source code

Next GDrive keeps your Google Drive on your Linux computer, for one or more Google accounts, with My Drive and shared drives. Each account works in one of two modes:

  • Mirror: the folders you choose are copied to your computer and kept in sync in both directions, so they work offline in any app.
  • Stream: your whole Drive appears in a folder, and files are downloaded only when you open them. Files and folders can be kept available offline.

Nothing is ever deleted permanently: deleted files go to the Google Drive trash, which you can browse and restore from. When a file changes in two places, both versions are kept. The app runs in the background with a tray icon, and everything it does is also available from the command line.

How it uses your Google account

Next GDrive asks for access to your Google Drive so it can copy, stream, upload, move and trash your files at your request. It talks directly to Google from your computer: there is no Next GDrive server, and no data is sent to the developers or anyone else. See the privacy policy for details.

Install

Flatpak, on any distribution

Kept up to date by flatpak update; the runtime it needs comes from Flathub.

flatpak install --user https://diegofaraujo.github.io/nextgdrive/io.github.diegofaraujo.NextGDrive.flatpakref

Ubuntu 24.04+, Debian 13+, Pop!_OS, Linux Mint 22

Download the .deb for your computer from the latest release, then:

sudo apt install ./nextgdrive_*.deb

Fedora, openSUSE

Download the .rpm from the latest release, then:

sudo dnf install ./nextgdrive-*.rpm

AppImage

Download it from the latest release, make it executable, and run it.

Packages exist for x86_64 (most PCs) and aarch64/arm64 (ARM computers).

Next GDrive is in early development: try it with data you have backed up. Questions, ideas and bug reports are welcome on GitHub.
